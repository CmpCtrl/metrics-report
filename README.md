# Metrics Report downloads

Installers for **CCG Metrics Report**, branded PDF reports from MoTeC and Link ECU logged data, by
[Competition Controls Group](https://competitioncontrols.com/metrics-report/).

## Download

**[Download the latest version](https://github.com/CmpCtrl/metrics-report/releases/latest/download/CCG_MetricsReport_Setup.exe)**
(Windows 10/11, 64-bit), or pick a version on the [Releases](https://github.com/CmpCtrl/metrics-report/releases) page.
Each release lists what changed.

Run the installer; no administrator rights are needed. It comes with an example project (D5 Racing's Corvette at
Barber Motorsports Park) to try everything on. To update, run the new installer over the old one; your projects are
kept.

The installer is signed by Competition Controls Group, LLC. If Windows SmartScreen shows a warning for a new release,
choose *More info* > *Run anyway* after checking the publisher name.
